# Nguyen Beauty Nails — Website

## Vorschau
Öffne `index.html` in einem Browser. Die Seite ist für Smartphones und Computer gestaltet.

## Enthalten
- Deutsche, responsive One-Page-Website
- Anklickbare Telefonnummer (`tel:`)
- Öffnungszeiten und Leistungen
- Google-Maps-Einbettung und Routen-Link
- Bewertungsbereich mit den von dir angegebenen 4,5 Sternen / 75 Rezensionen
- Galerie mit als Beispiel gekennzeichneten Bildern

## Vor dem Veröffentlichen unbedingt prüfen
1. Bestätige, dass alle Öffnungszeiten aktuell sind.
2. Bestätige die tatsächlichen Dienstleistungen und ergänze Preise, falls gewünscht.
3. Ersetze die Beispielbilder durch echte Fotos des Salons, wenn verfügbar.
4. Ergänze die korrekten Angaben für Impressum und Datenschutzerklärung. Die derzeitige Website enthält noch keine ausgearbeiteten rechtlichen Seiten.
5. Bitte beachte, dass Google Fonts, Unsplash-Bilder und die eingebettete Google-Karte eine Internetverbindung benötigen und externe Dienste laden.

## Kostenlos veröffentlichen über GitHub Pages
1. Erstelle ein kostenloses GitHub-Konto auf https://github.com/
2. Erstelle ein neues Repository (z. B. `nguyen-beauty-nails`).
3. Lade `index.html` in das Repository hoch.
4. Öffne **Settings → Pages**.
5. Wähle **Deploy from a branch**, Branch `main`, Ordner `/ (root)`, und speichere.
6. GitHub zeigt dir danach die kostenlose `github.io`-Adresse an. Das kann ein paar Minuten dauern.

GitHub Pages ist für statische Websites. Es gibt hier kein integriertes Online-Buchungssystem; die Terminvereinbarung erfolgt über den Telefon-Button.
